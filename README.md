# MD-Non-Equilibrium-Codes
This is a landing repository for the codes I developed to post process molecular dynamics simulations. The actual codes are in a private repository and can be accessed upon request. 
The codes are capable of doing the following: 
1. Extract modal energies of each molecule of the system from LAMMPS trajectory files
2. Extract the bond length frequencies of each chemical bond in the system
3. Simulate IR excitation of molecules - post processing codes and lammps input 
4. Simulate translational and rotational non equilibria
5. Track individual collisions of molecules
